# FIB — კლიენტის მობილური აპლიკაცია (დემო)

ქართულენოვანი კლიენტის აპლიკაციის კლიკებადი დემო, აწყობილი Stitch-ის პროექტიდან „FIB Mobile App Foundation“.
საიტის მთავარი მისამართი პირდაპირ აპლიკაციას ხსნის (Splash ეკრანი).

| ფაილი | რა არის |
|---|---|
| `index.html` | გადამისამართება აპლიკაციის პირველ ეკრანზე |
| `client-app/*.html` | 23 ეკრანი: ავტორიზაცია, მთავარი, AI ბრიფი და გუნდი, მოლაპარაკება, დაკვეთები |
| `client-app/index.html` | ყველა ეკრანის გალერეა, 5 ეტაპად |
| `client-app/DESIGN.md` | დიზაინ-სისტემა (ფერები, შრიფტები) |
| `assets/client-app.js` | აპლიკაციის ლოგიკა: გადასვლები, ფორმები, SMS კოდი, ჩატი |
| `assets/fib-bot.js` | **FIB ასისტენტი** ჩატებში — მზა პასუხები საკვანძო სიტყვებით. პასუხის დასამატებლად შეასწორეთ `KB` სია |
| `assets/fib-search.js` | **ძიება** (🔍 ზედა ზოლში): ბოლო ძიებები და რეკომენდაციები მათ მიხედვით. მოსაძებნი ჩანაწერები — `CATALOG` სია |
| `assets/client-app-data.js`, `assets/app-nav.js` | ეკრანების რიგი და მცურავი ნავიგაცია (წინა/შემდეგი) |
| `assets/logo.png`, `favicon.png`, `apple-touch-icon.png` | FIB ლოგო და ხატულები |
| `assets/img/` | ფოტოები |

დემოს მონაცემები (სახელი, ბრიფი, ბოლო ძიებები) ინახება მხოლოდ ბრაუზერში (localStorage); სერვერი არ არის.

## ონლაინ ვერსია (GitHub Pages)

საიტი ქვეყნდება `main` ბრანჩიდან. `git push`-ის შემდეგ ახალი ვერსია 1–2 წუთში გამოჩნდება.

## ლოკალურად გაშვება

```
powershell -ExecutionPolicy Bypass -File serve.ps1
```
შემდეგ: http://localhost:5173 — Tailwind CSS CDN-იდან იტვირთება, ამიტომ ინტერნეტი საჭიროა.
