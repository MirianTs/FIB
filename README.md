## ონლაინ ვერსია (GitHub Pages)

საიტი ავტომატურად ქვეყნდება GitHub Pages-ზე `main` ბრანჩიდან (საქაღალდე `/`).
ცვლილების ატვირთვის (`git push`) შემდეგ ახალი ვერსია 1–2 წუთში გამოჩნდება.

## ლოკალურად გაშვება

ფაილები ბრაუზერში პირდაპირაც იხსნება (`index.html`-ზე ორჯერ დაწკაპუნებით). ან ლოკალური სერვერით:

```
powershell -ExecutionPolicy Bypass -File serve.ps1
```
შემდეგ: http://localhost:5173

Tailwind CSS CDN-იდან იტვირთება, ამიტომ ინტერნეტი საჭიროა.
